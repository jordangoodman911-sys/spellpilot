# SpellPilot

## Downloaded the ZIP?

After extracting the ZIP, double-click **SpellPilot App.html**.

Keep these files together in the same folder:
- SpellPilot App.html
- p1.js
- p2.js
- p3.js
- p4.js
- p5.js

`index.html` is only the automatic GitHub Pages entry point. If you open it locally, it now redirects to **SpellPilot App.html**.

SpellPilot runs locally in your browser. Card metadata can be looked up from Scryfall when internet access is available.
